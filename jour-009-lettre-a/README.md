# Jour 009 - La lettre "a" dans un mot

## Objectif
Demander à l'utilisateur (en allemand, puis en anglais) et verifier qu'il contient la lettre "a".

## Lancer le script 
python main.py

## Notion travaillée  

- **Opérateur "in"** : Vérifie si un caractère ou une sous-chaîne se trouve à l’intérieur d'une chaîne de caractères, renvoie True ou False

## Vocabulaire du jour

### Allemand
| Mot | Traduction |
|---|---|
| Gib ein deutsches Wort ein | Entre un mot allemand |
| das Wort | le mot |
| enthält | contient |
| der Buchstabe | la lettre |

Point grammaire : `enthält` vient du verbe irrégulier `enthalten`(contenir), conjugué à la 3e personne du singulier.

### Anglais
| Mot | Traduction |
|---|---|
| Enter an English word | Entre un mot anglais |
| contains | contient |
| the letter | la lettre |
| does not contain | ne contient pas |
