# Jour 001 - Hallo Welt / Hello World

## Objectif
Premier script Python : afficher un message de bienvenue et demander le prénom de l'utilisateur, en allemand puis en anglais.

## Lancer le script
python main.py

## Notion Python travaillée  
- **print()** : pour afficher du texte a l’écran 
- **input()** : met le programme en pause et attend que l'utilisateur tape quelque chose (souvent en reference a ce qui est attendu)
- **f-strings** : une façon d’insérer une variable directement dans un texte. 

## Vocabulaire du jour

### Allemand
| Mot/Expression | Prononciation | Français
|---|---|---|
| Hallo Welt | ha-lo velt | Bonjour le monde ! |
| Wie heißt du? | vi haist dou | Comment t'appelles-tu ? |
| Schön | cheun | Beau/belle, ici "content(e)" |
| dich kennenzulernen | dish kènn-en-tsou-lèrnen | te rencontrer/ te connaître |

Point grammaire : "heißt" vient du verbe "heißen" (s'appeler),
verbe irrégulier, conjugué ici à la 2e personne du singulier (du heißt) .
source: dict.cc.

### Anglais

| Nice to meet you | Ravie de te rencontrer |
