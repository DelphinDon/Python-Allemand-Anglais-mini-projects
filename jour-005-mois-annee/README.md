# Jour 005 - Les mois de l'annee

## Objectif
Afficher les 12 mois de l'annee en allemand, puis en anglais, à l'aide d'une liste et d'une boucle.

## Lancer le script
python main.py

## Notion Python travaillée
- **Liste(list)** : ici une liste plus longue, répartie sur plusieurs lignes de code pour rester lisible.
- **Boucle for** : parcourt chaque élément de la liste un par un.

Point culture : comme les jours de la semaine, les mois prennent une majuscule en allemand. Et **der Monat(un mois)** different de **die Monate(les mois)**
- La boucle for monat in monate_de: se lit littéralement : "pour chaque monat dans la liste monate_de" → à chaque tour, Python prend un élément de la grande liste et le met temporairement dans la variable monat.
