# Jour 004 - Les jours de la semaine

## Objectif
Afficher les 7 jours de la semaine en allemand, puis en anglais à l'aide d'une liste et d'une boucle.

## Lancer le script
python main.py

## Notion python travaillee 
- **Liste(list)** : Une collection ordonnée de valeurs entre crochets []
- **Boucle for** : parcourt chaque élément d'une liste un par un 

## Vocabulaire du jour

### Allemand
| Mot | Traduction |
|---|---|
| Montag | Lundi |
| Dienstag | Mardi |
| Mittwoch | Mercredi |
| Donnerstag | Jeudi |
| Freitag | Vendredi |
| Samstag | Samedi |
| Sonntag | Dimanche |
| die Wochentage | les jours de la semaine |

Point culture : en allemand, tous les noms communs (dont les jours de la semaine) prennent une majuscule.

### Anglais

| Thursday | Jeudi |
| Friday | Vendredi |
| Saturday | Samedi |
| Sunday | Dimanche |
