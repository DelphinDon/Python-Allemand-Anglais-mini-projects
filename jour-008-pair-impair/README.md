# Jour 008 - Pair ou impair 

## Objectif
Demander un nombre à l'utilisateur et vérifier s'il est pair ou impair, en allemand puis en anglais.

## Lancer le script
python main.py

## Notion python travaillée
- **int()** : convertir un text en nombre entier
- **% (modulo)** : donne le reste d'une division, utilisé ici pour tester la parité.
- **if/else** : exécute un bloc de code différent selon qu'une condition est vraie ou fausse.

## Vocabulaire du jour

### Allemand
| Mot | Traduction |
|---|---|
| Gib eine Zahl ein | Entre un nombre | 
| gerade | pair |
| ungerade | impair |

Point grammaire : `eingeben` (entrer/saisir)est un verbe à particule séparable. Au présent et à l’impératif, `ein`se détache et va en fin de phrase (`Gib ... ein`)

### Anglais
| Mot | Traduction | 
|---|---|
| Enter a number | Entre un nombre |
| even | pair |
| odd | impair |
