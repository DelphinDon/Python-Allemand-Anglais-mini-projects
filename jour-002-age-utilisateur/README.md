# Jour 002 - Age de l'utilisateur

## Objectif
Demander l'age à l'utilisateur et afficher une phrase complète, en allemand puis en anglais.

## Lancer le script
python main.py

## Notion python travaillée  

- **input()** : récupère ce que l'utilisateur tape au clavier

- **f-strings** : insère une variable directement dans une phrase.

## Vocabulaire du jour

### Allemand 
| Mot | Traduction |
|---|---|
| Wie alt bist du? | Quel age as-tu ? |
| alt | vieux / âgé |
| Jahre | années | 
| Du bist X Jahre alt | Tu as X ans |

Point grammaire: "alt" est un adjectif, "Jahre" est le pluriel de "das Jahr" (l’année). En allemand, on dit littéralement "tu ees X année vieux/âgé".

### Anglais 
| Expression | Traduction |
|---|---|
| How old are you? | Quel age as-tu ? |
| You are  years od | Tu as X ans |
