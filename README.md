# Python + Allemand + Anglais — 180 mini-projets

## Objectif du dépôt
Ce dépôt regroupe 180 mini-projets Python réalisés quotidiennement,
sur 6 mois, dans le but de progresser en programmation Python tout
en consolidant du vocabulaire et de la grammaire en allemand et en anglais.

## Pourquoi ce projet ?

Apprendre à coder, ça prend du temps. Apprendre une langue, aussi.
Plutôt que de faire les deux séparément, j'ai décidé de les combiner :
chaque script Python que j'écris est aussi l'occasion d'apprendre du
vocabulaire et de la grammaire allemande et anglaise — deux langues
que je veux maîtriser pour la suite de mes études.

**La règle est simple** : au moins un mini-projet, jamais plus de
45 minutes chacun, mais jamais moins non plus. Certains jours,
j'en fais plusieurs si j'ai plus de temps ou plus d'énergie — l'objectif
n'est pas de respecter un calendrier strict au jour près, mais de
garder une progression régulière sur les 180 mini-projets.

## Organisation
Chaque dossier `jour-XXX-nom-du-projet` contient :
- `main.py` : le script Python du jour
- `README.md` : l'objectif, les notions Python travaillées,
  et le vocabulaire allemand/anglais appris ce jour-là
- Et peut etre plus...

## Progression
| Mois | Thème |
|---|---|
| Mois 1 (Jours 1-30) | Bases Python + vocabulaire de base |
| Mois 2 (Jours 31-60) | Logique + grammaire allemande et anglaise |
| Mois 3 (Jours 61-90) | Interfaces, fichiers, POO, API |
| Mois 4 (Jours 91-120) | Structures de données, algorithmes, POO avancée |
| Mois 5 (Jours 121-150) | Web, API REST, bots, automatisation |
| Mois 6 (Jours 151-180) | NLP, machine learning léger, projets avancés |
