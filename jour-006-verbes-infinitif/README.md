# Jour 006 - 20 verbes à l'infinitif

## Objectif
Créer deux listes de 20 verbes courants à l'infinitif, une en allemand, une en anglaise.

## Lancer le script
python main.py

## Notion Python travaillée
- **Liste(list)**
- **Boucle for**

## Vocabulaire du jour

### Allemand
| Verbe | Traduction |
|---|---|
| sein | etre |
| haben | avoir |
| werden | devenir |
| können | pouvoir |
| müssen | devoir (obligation) |
| sollen | devoir (recommandation) |
| wollen | vouloir |
| gehen | aller | 
| kommen | venir | 
| machen | faire | 
| sehen | voir |
| sagen | dire | 
| geben | donner |
| nehmen | prendre |
| wissen | savoir |
| finden | trouver | 
| denken | penser |
| sprechen | parler | 
| arbeiten | travailler |
| spielen | jouer | 

Point grammaire : l'infinitif allemand se termine presque toujours par "-en" (ou "-n").
