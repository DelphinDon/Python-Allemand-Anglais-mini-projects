# Jour 003 -Celsius -> Fahrenheit

## Objectif
Demander une temperature en degrés Celsius et la convertir en Fahrenheit,en allemand puis en anglais.

## Lancer le script
python main.py

## Notion Python travaillée  
- **float()** : Il convertir un text ( chaîne de caractères) en nombre decimal, nécessaire pour faire des calculs.
- **Operations mathématiques** multiplication(*), division(/), addition(+)

## Vocabulaire du jour

### Allemand
| Mot | Traduction |
|---|---|
| Wie viel Grad Celsius sind es? | Combien de degrés Celsius fait-il ? |
| Grad | degré(s) |
| entspricht | correspondre à / équivaut à

Point grammaire: "entspricht" vient du verbe "entsprechen" (correspondre), conjugué à la 3e personne du singulier.

### Anglais 
| Expression | Traduction |
|---|---|
| How many degrés Celsius is it? | Combien de degrés Celsius fait-il ? |
| is equal to | est egal à / équivaut à
