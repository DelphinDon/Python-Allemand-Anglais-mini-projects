# Jour 007 -Noms et articles

## Objectif
Creer une liste de 20 noms allemands avec leur article (der/die/das), et 20 noms anglais avec leur article (a/an/the).

## Lancer le script
python main.py

## Notion travaillee 
- **Liste(list)**
- **Boucle for**

## Vocabulaire du jour

### Allemand
| Nom avec article | Traduction |
|---|---|
| der Tisch | La table (masculin) |
| die lampe | la lampe (feminin) |
| das Buch | le livre (neutre) |
| der Stuhl | la chaise |
| die Tür | la porte |
| das Fenster | la fenetre | 
| der Hund | le chien | 
| die Katze | le chat |
| das kind | l'enfant | 
| der Baum | l'arbre | 
| die Blume | la fleur | 
| das Auto | la voiture | 
| der Freund | l'amie | 
| das Haus | la maison | 
| der Apfel | la pomme | 
| die Milch | le lait |
| das Brot | le pain | 
| der Himmel | le ciel |
| die Sonne | le soleil |

Point grammaire : Le genre d'un nom allemand ne se devine pas facilement, il faut l'apprendre avec son article comme un seul bloc `(der/die/das + nom)`.

### Anglais 
| Notion | Explication |
|---|---|
| a/an | un/une (a devant consonne, an devant voyelle) |
| the | le/la/les (chose precise ou unique) |

Point grammaire : l'anglais n'as pas de genre grammatical, contrairement à l'allemand.
